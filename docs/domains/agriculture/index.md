# agriculture Domain Pack (planned)

The **agriculture Domain Pack** is **not yet implemented**. CAP's Core schema is
domain-agnostic and ready to accept a agriculture Domain Pack via the
[RFC process](../../rfcs/domain-pack-template.md).

**Contributor wanted.** If you maintain a agriculture-relevant project and want
to lead this Pack, please open a [GitHub Discussion](https://github.com/cooperative-agent-protocol/cap-spec/discussions)
referencing the Domain Pack template.

Existing standards in this domain that a future Pack should consider:

- ISO TC23 (Tractors and machinery for agriculture and forestry)
- ISO 11783 (ISOBUS) — wire-level interop and field operation data
- AEF (Agricultural Industry Electronics Foundation) — certification
