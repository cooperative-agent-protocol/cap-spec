# forestry Domain Pack (planned)

The **forestry Domain Pack** is **not yet implemented**. CAP's Core schema is
domain-agnostic and ready to accept a forestry Domain Pack via the
[RFC process](../../rfcs/domain-pack-template.md).

**Contributor wanted.** If you maintain a forestry-relevant project and want
to lead this Pack, please open a [GitHub Discussion](https://github.com/cooperative-agent-protocol/cap-spec/discussions)
referencing the Domain Pack template.

Existing standards in this domain that a future Pack should consider:

- ISO TC23/SC15 (Forestry machinery)
- StanForD (forest data interchange)
