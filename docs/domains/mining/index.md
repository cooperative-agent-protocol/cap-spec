# mining Domain Pack (planned)

The **mining Domain Pack** is **not yet implemented**. CAP's Core schema is
domain-agnostic and ready to accept a mining Domain Pack via the
[RFC process](../../rfcs/domain-pack-template.md).

**Contributor wanted.** If you maintain a mining-relevant project and want
to lead this Pack, please open a [GitHub Discussion](https://github.com/cooperative-agent-protocol/cap-spec/discussions)
referencing the Domain Pack template.

Existing standards in this domain that a future Pack should consider:

- ISO TC82 (Mining)
- ISO 19296 (Earth-moving machinery and mining — Mobile machines working underground — Machine safety)
- Open Mining Format (OMF) for site data exchange
