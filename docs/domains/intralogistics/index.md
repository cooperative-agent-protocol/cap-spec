# intralogistics Domain Pack (planned)

The **intralogistics Domain Pack** is **not yet implemented**. CAP's Core schema is
domain-agnostic and ready to accept a intralogistics Domain Pack via the
[RFC process](../../rfcs/domain-pack-template.md).

**Contributor wanted.** If you maintain a intralogistics-relevant project and want
to lead this Pack, please open a [GitHub Discussion](https://github.com/cooperative-agent-protocol/cap-spec/discussions)
referencing the Domain Pack template.

Existing standards in this domain that a future Pack should consider:

- VDA 5050 (Interface for AGV)
- ISO TC110 (Industrial trucks)
- MAS (Master Control System for AGVs)
